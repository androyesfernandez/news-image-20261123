Sum up 23 November's world news in one image: a broadsheet front page for
Monday 23 November 2026 with 46 numbered stories from every region — Nepal's
PM holding talks with Modi in Delhi, fighting disrupting the Ebola response
in DR Congo, a Russian cargo ship still burning in the Gulf of Finland, and
Asia opening behind new market defences — plus a UTC timeline, six big
numbers of the day, a dotted world map with numbered pins, and a red DATE
CHECK box listing the big stories deliberately excluded because they were
first reported on 21–22 November.
